# Mentors Club

Личный тренажёр вопросов с собеседований: карточки в стиле Anki + доска Kanban по категориям.

## Локальный запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000, пароль задаётся переменной `SITE_PASSWORD` в `.env` (по умолчанию `changeme`).

## Загрузка реальных вопросов

1. Положи полный экспорт вопросов (как `123.txt`, но целиком — 1052 вопроса) в корень проекта.
2. Разбери его в JSON и проверь совпадение счётчиков категорий:
   ```bash
   npm run parse -- путь/к/файлу.txt
   ```
   Скрипт выведет таблицу `declared / parsed / match?` — если где-то `MISMATCH`, значит эвристика парсера не справилась с этим куском (обычно из-за многострочных ответов-списков); можно поправить `scripts/parse-questions.ts` или руками подчистить `prisma/seed-data.json`.
3. Залей в базу:
   ```bash
   npm run seed
   ```
   Сидинг идемпотентный — можно перезапускать после правок.

## Деплой на Vercel

Сейчас БД — SQLite-файл, годится только для локальной разработки. Для продакшена (доступ с компа и телефона одновременно) нужен настоящий Postgres:

1. Подключи Vercel Postgres (или Neon) к проекту на Vercel.
2. В `prisma/schema.prisma` смени `provider = "sqlite"` на `provider = "postgresql"`.
3. Пропиши `DATABASE_URL` из Vercel/Neon в переменные окружения проекта на Vercel и в `.env` локально (для повторного `migrate dev`/`seed` против прод-базы, если нужно).
4. `npx prisma migrate deploy` (Vercel может делать это в build-команде) и `npm run seed`.
5. В Vercel добавь `SITE_PASSWORD` — простой пароль-заглушка для единственного пользователя (это не полноценная авторизация, а лёгкая защита от чужих глаз).
